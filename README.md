# Orée

Outil d’information générale sur le marché spot en USDT. Un filtre automatique retient une paire, affiche un repère illustratif (−5 % / +6 %) et permet une veille de cours sur l’appareil. Aucun ordre n’est envoyé.

Ce n’est pas un conseil en investissement. Les crypto-actifs peuvent perdre toute valeur.

Les cours viennent d’une API publique de données de marché (`data-api.binance.vision`, repli `api.binance.com`). L’interface dit « Données de marché » et ne propose aucun lien vers une plateforme d’échange. Les pages Mentions légales et Confidentialité contiennent des emplacements à remplir avant une mise à disposition du public.

```bash
npm install
npm run dev
```
